# AP-2026-09-19 — compatibilidade de sintaxe no JSVM do PocketBase

- Status: candidato
- Escopo: projeto do cliente
- Task/SPEC: T1.16 / SPEC-1-004
- Sinal: a versão compilou e passou análise estática, mas a rota autenticada falhou em runtime ao usar spread de objeto na resposta.
- Evidência: log `POST /backend/v1/time-quality/reviews` com `ReferenceError: __spreadValues is not defined`; correção para objeto explícito passou QA 0.0.58.
- Regra reutilizável: em hooks PocketBase executados no JSVM, preferir objetos de resposta explícitos; não confiar que sintaxe moderna transpilada pelo frontend estará disponível no runtime do hook.
- Quando aplicar: ao escrever ou revisar hooks/rotas server-side, especialmente respostas `e.json`, mesmo quando o pipeline estático passar.
- Quando não aplicar: código TypeScript/React do frontend não executado pelo JSVM do PocketBase.
- Confiança: alta — falha observada no runtime, correção aplicada e pipeline completo passou.
- Privacidade: sem segredo, credencial, dado pessoal ou conteúdo bruto.
